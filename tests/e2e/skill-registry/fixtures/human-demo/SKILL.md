# Acceptance status

Use this Skill when the user asks for a work report, handover, or delivery summary.

Respond in the user's language. Organize the report into these sections:

1. Result: describe the work completed and the files produced.
2. Verification: list the checks actually performed and their results.
3. Next step: give one practical next action, or state that the task is complete.

Keep the report concise. Distinguish confirmed results from anything still unverified.
Read the relevant workspace files before reporting on their contents.
